Cursor

정의

Cursor API는 유니티 런타임에서 운영체제의 마우스 커서를 표시/숨김, 잠금/제한, 이미지 변경 같은 방식으로 제어할 수 있게 해주는 유니티엔지의 기능임. 게임 플레이 상황(공격 가능, 이동가능, 상호작용 가능 등)을 즉각적으로 전달하는 UX 피드백 수단으로 자주 사용 됨.

핵심 규칙

상태가 변할때만 커서를 갱신해야합니다. 매 프레임 SetCursor를 반복 호출 하면 불필요한 비용과 예측 불가능한 깜빡임/지연이 생길 수 있음.

커서 텍스처의 HotSpot(클릭 기준점) 을 먼저 설계해야 함. 이미지 중심이 아니라 "실제 클릭 포인트"에 맞추는게 UX 품질을 좌우함.

커서는 컨텍스트 우선순위가 필요함. 예: UI 위에서는 UI우선 적 위에서는 공격 우선, 그 외는 이동/기본 커서 등 규칙을 정해 충돌을 방지함.

드래그/클릭 유지 중에는 커서 변경을 제한하는 등, 입력 중 UX 안정성 정책을 둬야함.

플랫폼별 동작 차이를 고려해 CursorMode 선택과 텍스처 해상도/포맷을 관리 해야함.

구성 요소

Cursor(UnityEngine.Cursor): 커서 표시/잠금/이미지 변경을 담당하는 Unity 내장 클래스

Texture2D: 커서로 사용할 이미지 리소스(알파 포함 권장)

Hotspot: 커서 이미지에 "클릭이 발생하는 기준점" 좌표(보통 픽셀 단위

CursorMode: 커서 렌더링 방식(플랫폼/성능/호환성에 영향).

Cursor.visible: 커서 표시/숨김 토글

Cursor.lockState: 커서 잠금/제한 상태(None/Locked/Confined).

Context Cursor: 오브젝트/상태에 따라 커서 모양이 달라지는 UX 패턴

유사함수

Cursor.SetCursor: 커서 이미지를 텍스처로 교체하고 HotSpot/모드를 지정함.

Cursor.visible: 커서를 화면에 표시할지, 숨길지 설정함.

Cursor.lockState: 커서의 잠금/제한 상태를 설정함.

Input.mousePosition: 커서 위치 기반 상호작용 판단에 사용되는 화면 좌표를 제공함.

ScreenPointToray: 화면 좌표를 월드 레이로 변환해 무엇 위에 있는 판단에 활용 함.

주의사항

Hotspot이 어긋나면 클릭 정확도가 떨어지고 커서가 붙어 보이지 않음.

커서를 바꾸는 로직이 여러 곳에 흩어지면 커서가 서로 덮어쓰며 깜빡이는 문제가 생기기 쉬움.

UI 위에서도 월드 판정이 계속되면 UI 조작 중 커서모양이 튀는 문제가 자주 발생함.

플랫폼/해상도/OS 설정에 따라 커서 크기/선명도가 달라질 수 있어, 너무 큰 텍스처나 미세한 디테일은 손해일 수 있음.

커서를 숨기거나 잠그는 기능은 에디터/빌드/플랫폼에서 체감이 다를 수 있으므로, 실제 타깃 환경에서 확인 필요함.
