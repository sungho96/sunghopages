2D Enemy Patrol AI

정의

2D 몬스터 패트롤 AI는 몬스터 구간을 자동으로 이동하며 순찰하도록 만드는 기본 인공지능 로직임.

유니티 2D 환경에서는 주로 이동 방향제어, 시간 기반 방향 전환, Rigidbody2D 이동 처리, 애니메이션 상태 전환을 조합하여 구현함.

패트롤 AI는 모슨터 행동 시스템의 가장 기본적인 형태로 플레이어를 추적하거나 공격하기 전 기본 행동 상태로 사용되는 경우가 많음. 간단한 규칙만으로 자연스러운 몬스터 움직임을 구현할 수 있는 특징 임.

핵심규칙

이동 방향을 명확하게 관리해야 함.

패트롤 AI에서는 몬스터가 좌우 이동 방향을 지속적으로 유지하다가 특정 조건에서 방향을 전환해야함.

시간 기반 패턴을 사용하면 자연스러운 움직임이 만들어짐.

패트롤 AI는 보통 시간을 기준으로 이동 패턴을 제어함.

이동 속도에 변화를 주면 AI 움직임이 자연스러워짐.

패트롤 AI에서 모든 몬스터가 항상 동일한 속도로 움직이면 인공지능이 인위적으로 보일 수 있음.

물리 기반 이동은 Rigidbody2D를 사용 하는 것이 안정적임

유니티 2D에서는 이동을 구현할 때 Transform, Rigidbody2D

패트롤 AI 처럼 충돌과 물리 상호 작용이 있는 오브젝트는 Rigidbody2D를 이용한 이동 방식이 더 안정적임.

구성 요소

Move Direction

몬스터가 이동할 방향을 나타내는 값으로, 일반적으로 좌우 이동을 위해 -1 또는 1 값을 사용.

Patrol Timer

몬스터가 현재 방향으로 이동하는 시간을 측정하는 타이머.

Move Speed

몬스터가 이동할 때 사용하는 기본 속도.

Speed Variance

기본 이동 속도에 랜덤 변화를 주기 위한 속도 변동 범위.

Rigidbody2D

유니티 2D 물리 시스템에서 이동과 충돌 계산을 담당하는 컴포넌트

Animation State

몬스터 행동 상태에 따라 변경되는 애니메이션 상태

유사함수

Random.Range

지정한 범위 내에서 랜덤 값을 생성하여 AI 패턴에 변화를 줄 때 사용.

Mathf.Abs

값의 절대값을 반환하여 이동 여부나 속도 크기를 판단할 때 사용.

Time.deltaTime

프레임 시간 기반으로 타이머를 계산하여 일정한 시간 흐름을 유지하는 데 사용.

Rigidbody2D.velocity

물리 기반으로 오브젝트 이동 속도를 직접 제어하는 속성.

주의사항

패트롤 시간 설정이 너무 짧으면 AI가 부자연스러워짐.

패트롤 시간이 지나치게 짧으면 몬스터가 지속적으로 방향을 바꾸면서 떨리는 움직임을 보일 수 있음.

속도 랜덤 범위가 너무 크면 움직임이 불안정해질 수 있음.

속도 변화 범위가 과도하게 크면 몬스터 이동 패턴이 불규칙해 보일 수 있으므로 적절한 범위 설정이 필요함.

애니메이션 상태와 이동 상태가 어긋날 수 있음

이동 중인데 Idle 애니메이션이 재생되거나
