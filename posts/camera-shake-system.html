Camera Shake System

정의

Camera Shake System은 카메라 위치를 짧은 시간 동안 랜덤하게 흔들어, 공격·피격·폭발 등의 순간적인 충격을 시각적으로 전달하는 연출 시스템임.

실제 게임 플레이에 직접 영향을 주는 기능은 아니지만, 타격감과 피드백을 강화하여 플레이어가 이벤트의 강도를 체감할 수 있도록 도와주는 역할을 수행함.

주로 피격 반응, 스킬 충돌, 보스 패턴, 폭발 연출 등 순간적인 임팩트 표현에 사용됨.

핵심 규칙

카메라는 흔들린 뒤 반드시 원래 위치로 복구되어야 함.

Camera Shake는 일시적인 연출이므로, 흔들림 종료 후 원래 카메라 위치를 정확히 복원해야 카메라 드리프트 현상이 발생하지 않음.

흔들림 강도와 지속 시간은 분리해서 관리해야 함.

강도(Magnitude)는 얼마나 크게 흔들릴지를 의미하고, 지속 시간(Duration)은 얼마나 오래 흔들릴지를 의미함. 두 값을 분리해야 상황별 연출 조절이 쉬워짐.

동시에 여러 흔들림 요청이 들어올 경우 처리 정책이 필요함.

기존 흔들림을 중단하고 새 흔들림으로 교체할지, 중첩할지 명확한 기준이 있어야 함.

랜덤 위치 이동은 LocalPosition 기준으로 처리하는 것이 안정적임.

부모 오브젝트 구조가 존재하는 경우 World Position보다 Local Position 기반 제어가 더 안전하게 동작함.

카메라 이동 시스템과 충돌하지 않도록 관리해야 함.

Follow Camera, Cinemachine, Camera Controller 등 다른 카메라 제어 시스템과 동시에 동작할 경우 위치 충돌이 발생할 수 있음.

구성 요소

Original Position

흔들림 시작 전 카메라의 원래 위치 정보임.

Magnitude

카메라가 얼마나 크게 흔들릴지를 결정하는 값임.

Duration

흔들림이 유지되는 전체 시간 값임.

Random Offset

매 프레임 랜덤하게 생성되는 위치 오프셋 값으로, 카메라 흔들림의 핵심 요소 역할을 수행함.

Coroutine

짧은 시간 동안 반복적으로 위치를 변경하고 원래 위치로 복구하기 위한 시간 기반 처리 방식임.

Shake Request

피격, 폭발, 공격 등 외부 이벤트에서 Camera Shake를 호출하는 요청임.

유사함수

Random.Range

지정한 범위 내 랜덤 값을 반환하여 흔들림 오프셋 계산에 사용됨.

Transform.localPosition

카메라의 로컬 위치를 제어하여 흔들림을 적용할 때 사용됨.

StopCoroutine

기존 흔들림 Coroutine을 중단하여 중복 실행을 방지할 때 사용됨.

Time.deltaTime

흔들림 지속 시간을 프레임 독립적으로 계산할 때 사용됨.

StartCoroutine

시간 기반 흔들림 연출을 실행할 때 사용하는 함수임.

주의사항

원래 위치 저장 시점이 잘못되면 카메라 위치가 누적 이동될 수 있음.

흔들림 도중의 위치를 기준으로 다시 저장하면 카메라가 점점 밀려나는 문제가 발생할 수 있음.

여러 Camera Shake가 동시에 실행되면 흔들림이 비정상적으로 커질 수 있음.

중복 Coroutine 실행을 허용할 경우 흔들림 값이 누적될 수 있음.

Magnitude 값이 지나치게 크면 플레이어 피로도가 증가할 수 있음.

강한 흔들림은 타격감은 증가시키지만, 장시간 플레이 시 화면 피로를 유발할 수 있음.

Update 기반 카메라 이동과 동시에 사용하면 위치 충돌이 발생할 수 있음.

Follow Camera가 위치를 계속 갱신하는 상황에서 Shake가 동시에 위치를 변경하면 비정상적인 떨림 현상이 발생할 수 있음.

짧은 연출이라도 매 프레임 위치를 변경하므로 과도한 연산은 피해야 함.

Shake 내부에서는 최소한의 계산만 수행하고, 무거운 로직은 외부에서 처리하는 구조가 안정적임.
