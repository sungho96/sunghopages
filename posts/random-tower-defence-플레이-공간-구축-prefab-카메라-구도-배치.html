작업내용

prefab을 활용한 playground 제작및 카메라 프레이밍 위치 설정 작업

핵심개념

prefab : 재사용 가능한 게임 오브젝트

장점: 반복 배치 + 원본 유지 + 수정 일괄 적용

반복적으로 사용되는 요소 효율적 관리, 복제품 자동 일괄 관리 가능,프리팹 중첩 가능

트러블 슈팅

현상 :Game View에서 원하는 카메라 프레이밍 안나옴

원인 : Scene에서 바라보는 화면과 실제 카메라가 바라보는 화면에서 차이가 발생

해결 : ctrl+shift+f 를 활용하여 Scene과 Game view 일치하게 변경

배운점 : 초기 카메라 구도가 중요한데 저 기능을 사용해보자.
