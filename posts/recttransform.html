RectTransform

최종 수정일: 2월 20일

Canvas/Scaler 설정: Overlay + Scale With Screen Size(Reference Resolution 기준

툴팁 패널 RectTransform: 앵커·피벗·크기(Width/Height) 확인

정의

RectTransform은 Unity UI에서 위치/크기/정렬 기준을 담당하는 Transform이며,

Canvas(UI 루트) 기준 좌표계를 사용함.

툴팁 UI는 보통 RectTransform으로 패널(DetailPanle)의 표시/숨김을 제어하고, 필요하다면 포인터 위치에 맞춰 UI 좌표로 배치함.

핵심규칙

UI 배치는 Transform.postition 보다 RectTransform의 anchoredPosition/Anchor/Pivot 개념이 중심임

UI 패널은 보통 SetActive로 표시 상태를 관리하고, 내용(Text)는 표시 직전에 갱신함.

툴팁이 " 마우스 근처에 뜨는 UI"라면 포인터(screen 좌표)를 Canvas 로컬 좌표로 변환해 RectTransform에 적용하는 방식이 기본임.

툴팁 패널은 화면 밖으로 나갈 수 있으므로, 실제 서비스에서는 클램프 처리를 고려함.

구성 요소(용어 정리)

Canvas : UI가 그려지는 루트, Render Mode에 따라 좌표 변환 방식이 달라질 수 있음.

RectTransform: UI 전용 Transform, 앵커/피봇/사이즈/앵커 기준위치를 가짐

DetailPanel(툴팁 패널) : 상세 정보 UI. 보통 처음에 비활성화 후 필요할 때 활성화.

GridPanel(Content) : 아이템 슬롯들이 들어가는 부모. GridLayoutGroup 같은 레이아웃 컴포넌트가 붙는 경우가 많음.

주의 사항

Anchor가 바뀌면 같은 값도 의미가 바뀜.

Pivot은 위치 계산과 회전/스케일 기준을 바꿈.

Transform.Position으로 UI를 만지면 예상과 다르게 보일 수 있음.

부모 Canvas/부모 RectTransform의 스케일 영향이 큼.

World Space Canvas에서는 좌표감각이 달라짐.
