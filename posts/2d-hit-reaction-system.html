2D Hit Reaction System

정의

Hit Reaction System은 캐릭터가 공격을 받았을 때 데미지 적용뿐만 아니라, 넉백, 무적 시간, 피격 연출, HP UI 갱신, 사망 처리 등을 하나의 흐름으로 연결하는 피격 반응 처리 구조 임.

단순히 HP만 감소시키는 방식이 아니라, “맞았을 때 캐릭터가 어떻게 반응해야 하는지”를 관리하는 시스템 임.

주로 플레이어 피격, 몬스터 피격, 투사체 충돌, 접촉 데미지, 보스 패턴 피격 처리 등에 사용됨.

핵심 규칙

데미지 판정과 피격 반응 처리는 분리되어야 함.

충돌을 감지하는 객체는 “맞았다”는 사실만 전달하고, 실제 HP 감소나 무적 체크는 피격 대상 쪽에서 처리하는 구조가 안정적임.

피격 무적 상태를 반드시 체크해야 함.

적과 계속 접촉 중이거나 여러 Collider가 겹치는 상황에서는 데미지가 반복 적용될 수 있으므로, 일정 시간 동안 추가 피격을 막는 무적 처리가 필요함.

넉백 방향은 공격자와 피격자의 위치 관계를 기준으로 계산해야 함.

피격자가 공격자보다 오른쪽에 있으면 오른쪽으로, 왼쪽에 있으면 왼쪽으로 밀려나도록 방향을 계산해야 자연스러운 피격 반응이 됨.

HP 감소 후 UI 갱신이 함께 이루어져야 함.

실제 체력 값이 변경되었는데 HP Bar가 갱신되지 않으면 화면 정보와 내부 데이터가 달라지므로, 체력 변경 후 UI Refresh 처리가 필요함.

사망 상태에서는 추가 피격 처리를 막아야 함.

이미 사망한 캐릭터가 계속 데미지를 받거나 넉백되는 상황을 방지하기 위해, 사망 여부를 먼저 검사해야 함.

구성 요소

피격 판정 객체

적, 투사체, 함정처럼 플레이어에게 데미지를 줄 수 있는 오브젝트임.

Damage Source

공격자가 가지고 있는 데미지 정보를 의미하며, 접촉 데미지나 공격력 값을 제공하는 역할을 함.

Health Component

현재 HP, 최대 HP, 사망 여부를 관리하고 실제 데미지 적용을 담당하는 컴포넌트.

Hit Reaction Component

넉백, 무적 시간, 피격 색상 변화, 충돌 무시 등 피격 후 반응을 처리하는 컴포넌트.

Knockback Force

피격 시 캐릭터를 밀어내기 위한 힘 값으로, 보통 X축 방향과 Y축 방향을 나누어 계산함.

HP UI

현재 체력 상태를 화면에 표시하는 UI 요소로, HP가 변경될 때 함께 갱신되어야 함.

유사함수

GetComponent

같은 오브젝트에 붙어 있는 특정 컴포넌트를 가져올 때 사용하는 함수.

CompareTag

충돌한 대상이 특정 Tag를 가지고 있는지 빠르게 확인하는 함수.

Mathf.Max

최소값을 보장하거나 데미지 계산 결과를 제한할 때 사용할 수 있는 함수.

주의사항

피격 처리 함수 안에 모든 로직을 몰아넣으면 유지보수가 어려워짐.

충돌 감지, HP 감소, 피격 연출, UI 갱신, 사망 처리를 한 곳에서 모두 처리하면 코드가 복잡해지므로 역할별로 나누는 것이 좋음.

무적 체크가 없으면 접촉 데미지가 지나치게 빠르게 반복될 수 있음.

적과 플레이어가 붙어 있는 상태에서는 충돌 이벤트가 여러 번 발생할 수 있으므로, 피격 쿨다운 처리가 필요함.

HP UI 갱신 타이밍을 놓치면 실제 HP와 화면 표시가 달라질 수 있음.

데미지 적용 직후 UI를 갱신하거나, 체력 변경 이벤트를 통해 UI가 자동 반영되도록 구조를 잡아야 함.

넉백 방향 계산 기준이 잘못되면 캐릭터가 공격자 쪽으로 밀릴 수 있음.

공격자 위치와 피격자 위치를 비교하여 어느 방향으로 밀어낼지 명확히 계산해야 함.

사망 처리 이후에는 넉백이나 추가 데미지 처리를 중단해야 함.

HP가 0 이하가 된 뒤에도 피격 반응이 계속 실행되면 사망 상태와 물리 반응이 충돌할 수 있음.
