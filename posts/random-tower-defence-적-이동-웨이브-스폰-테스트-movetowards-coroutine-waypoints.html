Mathf-Clamp

최종 수정일: 1월 24일

Mathf.Clamp

형식

public static float Clamp (float value , float min , float max );

결과값

최소값과 최대값 사이의 부동 소수점 결과입니다.

설명

주어진 값을 주어진 최소 부동소수점 값과 최대 부동소수점 값 사이로 제한합니다. 주어진 값이 최소값과 최대값 범위 내에 있으면 해당 값을 반환합니다.

주어진 부동 소수점 값이 최소값보다 작으면 최소값을 반환합니다. 주어진 값이 최대값보다 크면 최대값을 반환합니다. Clamp 함수를 사용하여 값을 최소값과 최대값으로 정의된 범위 내로 제한할 수 있습니다.최소값이 최대값보다 크면 정의되지 않은 값을 반환합니다.

Mathf.Clamp01

형식

Mathf.Clamp01(float num)

결과값

값을 0에서 1 사이로 제한하고 해당 값을 반환합니다.

값이 음수이면 0이 반환 되고, 값이 1보다 크면 1이 반환 됩니다.

설명

이 함수는 특히 퍼센트 값을 다룰 때 유용합니다.
