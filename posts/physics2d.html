Physics2D

정의

Physics2D는 Unity에서 2D 오브젝트의 충돌, 감지, 이동 판정을 처리하는 물리 시스템임.

주로 RayCast, overlapbox, Rigidbody2D, Collider2D, IgnoreCollision 등을 이용해 바닥체크, 사다리 감지, 충돌 처림, 일시적 통과 처리 등을 구현함.

핵심 규칙

감지 와 이동 처리는 분리해야함.

Raycast, OverlapBox는 상태 확인용이고, Rigidbody2D.velocity나 gravityScale은 실제 이동 처리용임.

검사 방식은 목적에 맞게 나눠야 함.

바닥 확인은 Raycast, 특정 구역 감지는 Overlap 계열이 더 적합한 경우가 많음.

충돌 수시는 필요한 순간에만 적용해야함.

계속 무시하면 관통 문제가 생길 수 있으므로, 조건부로 잠깐만 해제하는 방식이 안전함.

IgnoreCollision은 콜라이더끼리만 적용됨.

레이어 전체가 아니라 두 Collider2D 사이의 충돌 관계만 바꾸는 방식임.

충돌 무시 후 복구 처리가 반드시 있어야 함.

무시만 하고 다시 켜지 않으면 이후 물리 동작이 꼬일 수 있음.

위치 판단은 bounds 기준으로 보는 것이 안정적임.

특히 발 위치, 머리 위치, 사다리 꼭대기 판정은 transform보다 collider bonuds기준이 더 정확한 경우가 많음.

구성 요소

Physics2D

Unity의 2D 물리 검사 기능을 담당하는 클래스

Rigidbody2D

2D 오브젝트의 이동, 속도, 중력 반응을 담당함.

Collider2D

2D 충돌 판정 영역임.

OverlapBox

박스 범위 안에 들어온 콜라이더를 감지하는 방식임.

LayerMask

검사할 레이어를 제한하는 필터 임.

bounds

콜라이더가 차지하는 실제 월드 공간 범위

IgnoreCollision

특정 두 콜라이더 사이의 충돌을 끄거나 다시 켜는 기능임.

IgnoreCollisionTemporarily

일정 시간 동안만 충돌을 무시하고 다시 복구하는 처리 방식임.

유사함수

Physics2D.Raycast

바닥, 벽, 전방 장애물 등을 선형으로 검사할 때 사용함.

Physics2D.OverlapBox

박스 범위 안에서 사다리나 특정구역 충돌체를 감지 할 떄 사용 함.

Physics2D.OverlapCircle

원형 범위 안의 충돌체를 간단하게 검사할 때 사용함.

physics2D.IgnoreCollision

특정 두 Collider2D 사이의 충돌을 직접 켜고 끌 때 사용 함.

physics2D.IgnoreLayerCollision

개별 콜라이더가 아니라 레이어 단위로 충돌 여부를 제어 할 때 사용함.

주의사항

Rigidbody2D와 Collider2D 역할이 섞이면 물리 흐름이 불안정해질 수 있음.

OverlapBox 크기나 위치가 조금만 어긋나도 감지 결과가 달라 질 수 있음.

IgnoreCollision은 대상 콜라이더가 정확해야 원하느 충돌만 무시 할 수 있음.

충돌 무시 시간이 너무 짧으면 다시 걸리고, 너무 길면 원치 않는 관통이 생길 수 있음.

IgnoreCollisionTemporarily 같은 방식은 특히 위에서 아래로 내려갈 떄 상단 발판에 걸리지 않게 만든느처리에서 중요함.

bounds 기준 계산 없이 Transform 위치만 믿으면 발 위치나 꼭대기 판정이 어긋날 수 있음.
