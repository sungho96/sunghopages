Unity UI Button (Button.onClick)

개요

UnityEngine.UI.Button은 클릭 입력을 onClick 이벤트로 노출합니다.

onClick은 UnityEvent 기반이며, Inspector 연결 또는 코드(AddListener) 로 콜백을 등록할 수 있습니다.

API 요약

Button.onClick

타입: UnityEvent

역할: 버튼 클릭 시 등록된 리스너를 호출

AddListener / RemoveListener

클릭 시 Method 호출을 등록

button.onClick.AddListener(Method)

동일한 Method 등록을 해제

button.onClick.RemoveListener(Method)

RemoveListener는 “전체 제거”가 아니라 지정한 메서드 1개만 제거합니다.

실행 규칙

onClick 호출 시점

사용자가 버튼을 클릭(또는 Submit 입력)했을 때 호출됩니다.

버튼/오브젝트가 비활성화되거나, interactable=false인 경우 일반적으로 클릭 이벤트가 발생하지 않습니다.

리스너 중복 등록

AddListener는 같은 메서드를 여러 번 등록할 수 있습니다.

중복 등록되면 클릭 1회에 여러 번 호출됩니다.

따라서 “UI가 꺼졌다 켜지는 구조”에서는 중복 방지 패턴이 필요합니다.

주의사항

1) “Inspector 연결 + 코드 AddListener” 혼용

둘을 동시에 쓰면 클릭 1회에 콜백이 2번 실행될 수 있습니다.

하나의 방식으로 통일하는 것을 권장합니다.

2) Awake에서 AddListener + OnEnable에서 Remove/Add

둘 다 쓰면 동작은 가능하지만 구조적으로 중복이 생깁니다.

문서 관점에서는 한 곳으로 통일하는 것이 더 명확합니다.

예: OnEnable에서만 “중복 방지 + 등록”을 담당

3) null 체크

Button 참조가 비어 있으면 런타임에서 이벤트 연결이 실패합니다.

필수 참조라면 SerializeField + Inspector 할당을 전제로 하고, 개발 단계에서는 Debug.LogError로 빠르게 발견하는 방식이 좋습니다.
