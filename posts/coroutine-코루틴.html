Coroutine(코루틴)

정의

Coroutine은 유니티에서 여러 프레임에 걸쳐 순차적으로 실행되는 비동기 흐름 제어 방식임.

일반 함수는 한 프레임 안에서 모든 코드가 실행되지만, Coroutine은 특정 시점에서 실행을 잠시 멈추고 다음 프레임이나 일정 시간이지난 후 다시 실행을 이어갈 수 있음.

이를 통해 시간 기반 로직(딜레이, 쿨타임,연출, 단계별 처리)을 Update 루프 없이 간결 하게 구현 할 수 있음.

핵심 규칙

IEnumerator 반환 구조를 사용해야 함.

Coroutine 함수는 반드시 IEnumerator 반환 타입을 사용하며, 실행 흐름을 yield 키워드로 제어함.

StartCoroutine으로 실행해야 함.

Coroutine은 일반 함수 호출이 아닌 StartCoroutine()을 통해 실행해야 Unity의 프레임 흐름에 등록됨.

yiled 구문이 실행 흐름을 제어함.

yiled는 코루틴의 실행을 특정 시점까지 중단시키며, 이후 조건이 충족되면 다음 코드가 이어서 실행됨.

프레임 기반 또는 시간기반 제어가 가능하다.

한 프레임 대기, 특정 시간 대기, 조건 대기 등 다양한 흐름 제어가 가능함.

코루틴은 Update 대체가 아니라 보조 흐름 제어 도구

지속적인 입력 처리나 물리 계산은 Update나 FixUpdate에서 처리하고, 코루틴은 연출이나 타이밍 제어에 사용하는 것이 일반적임.

구성 요소

Coroutine

여러 프레임에 걸쳐 순차적으로 실행되는 유니티의 비동기 실행 구조.

IEnumerator

코루틴 함수에서 사용하는 반환 타입으로, 실행 흐름을 단계적으로 관리 할 수 있게 해줌.

Yield

코루틴 실행을 특정 시점까지 일시 정지시키는 키워드

Yield Instruction

코루틴의 대기 조건을 정의하는 객체로, 시간 대기나 프레임 대기 등의 흐름을 제어함.

StartCoroutine

Coroutine 실행을 Unity 엔진의 프레임 루프에 등록하는 함수.

유사함수

Invoke()

특정 함수를 일정 시간 후 한 번 실행하는 지연 호출 기능.

InvokeReperation()

지정한 시간 간격으로 함수를 반복 실행하는 타이머 기반함수.

WaitForSeconds()

Coroutine에서 지정한 시간 동안 실행을 대기하는 시간 기반 Yield Instruction.

WaitForEndOfFrame()

현재 프레임의 렌더링이 끝난 뒤 다음 단계가 실행되도록 하는 Yield Instruction.

WaitUnitil()

특정 조건이 만족될 때까지 Coroutine 실행을 대기시키는 Yield Instruction.

주의사항

Coroutine은 자동으로 종료되지 않음.

루프 구조로 작성된 코루틴은 명시적으로 종료 조건을 만들지 않으면 계속 실행될 수 있음.

GameObject가 비활성화되면 코루틴도 중단됨.

MonoBehaviour가 비활성화되거나 오브젝트가 Destory되면 해당 코루틴도 함께 종료된다.

Coroutine은 멀티스레드가 아님.

코루틴은 유니티의 메인 스레드에서 실행되며, 실제 병렬 처리 방식이 아님.

너무 많은 코루틴은 성능에 영향을 줄 수 있음.

동시에 많은 코루틴이 실행되면 프레임 관리 비용이 증가 할 수 있으므로 관리가 필요함.

상태 제어 없이 실행하면 중복 실행 문제가 발생할 수 있음.

같은 코루틴이 여러번 시작되면 의도하지 않은 중복 로직이 발생 할 수 있으므로 실행 상태를 관리하는 것이 중요함.
