Anim_Blend

최종 수정일: 2월 20일

정의

AnimBlend(Animator Blend Tree 기반 애니메이션 블렌딩)은 캐릭터의 이동 정도를 연속 값으로 표현하고, 그 값에 따라 여러 애니메이션 클립(Idle/Run 등)을 자연스럽게 섞어 재생하는 Unity 애니 메이션 구성 방식. 핵심은 "상태를 딱 잘라 바꾸는 것"이 아니라, 값이 변하는 만큼 애니메이션도 부드럽게 변하게 만드는 것.

핵심 규칙

Blend Tree는 Float 파라미터 1개를 중심으로 설계함.

블렌드 값은 ‘즉시 점프’가 아니라 ‘보간’으로 움직임.

갑자기 0→1로 튀면 블렌드의 장점이 사라짐.

Lerp/SmoothDamp처럼 완만한 변화가 기본임.

블랜드 값은 '즉시 점프'가 아니라 보간으로 움직임.

Animator 제어는 파라미터 Set이 중심이고, 상태 강제 재생은 최소화함.

이동 블렌드는 이동계열만 담당함.

구성 요소

Animator: 애니메이션 상태머신과 파라미터를 통해 캐릭터 애니메이션을 제어하는 컴포넌트

Animator Controller: State,Transition, Parameter, Blend Tree등을 포함한 애니메이션 제어 에셋

Blend Tree: 하나의 파라미터 값을 기준으로 여러 애니메이션 클립을 섞어 재생하는 노드

Float Parameter: Blend Tree 입렵값으로 사용되는 연속 값 파라미터

Threshold: 특정 파라미터 값에서 어떤 클립이 얼마나 반영되는지 결정하는 기준점

Damping: 파라미터 값이 근변하지 않도록 부드럽게 따라가게 만드는 처리

Base Layer: 기본 전신 애니메이션이 재생되는 레이어

유사함수

Animator.SetFlaot: Blend Tree 입력 파라미터를 갱신해 블렌딩 결과를 바꿈.

Mathf.SmoothDamp: 튀지 않게 더 자연스러운 감쇠로 값을 추종시킴.

Time.deletaTime: 프레임 의존을 줄이고 보간 속도를 일정하게 유지하는데 사용함.

Animator.StringToHash: 파라미터/상태 이름을 해시로 변환해 문자열 비용을 줄일때 사용함.

주의사항

Update에서 매프레임 Play로 같은 상태를 강제하면 Blend Tree 장점이 망가짐.

GetComponent를 매 프레임 호출하면 불필요한 비용이 생김.

Threshold와 실제 애니메이션 속도/루트모션이 어긋나면 미끄러짐이 보일 수 있음.

0/1만 쓰는 Blend Tree는 부드러운 전환은 얻지만 확장성은 낭비가 될 수 있음.

블렌드 값 보간 속도가 너무 크면 '딱딱한 전환',너무작으면 '반응이 느림'이 됨.

이동 블렌드와 다른동작이 같은 레이어에서 경쟁하면 덮어쓰기 문제가 생김.
