프리팹(prefab) & 인스턴스(Instance)

최종 수정일: 1월 24일

Prefab

정의

Unity의 프리팹 오브젝트를 생성, 구성 및 저장할 수 있습니다.게임 오브젝트 모든 구성 요소, 속성 값 및 자식 게임 오브젝트를 포함하는 재사용 가능한 에셋입니다

Instance

정의

인스턴스화란, 어떤 대상을 실존하는 무언가로 찍어내는 것을 말한다. 유니티에서 인스턴스화는 게임 도중에 만들어 놓은 오브젝트를 생성하는 것을 말합니다.

선언

public GameObject target;

void Start()

{

Instantiate(target);

}

장점

씬 뷰, 계층 구조 및 인스펙터를 사용하여 프리팹을 빠르고 쉽게 설정하고 테스트하고 수정합니다.

코드를 변경하지 않고도 인스턴스화할 프리팹을 변경합니다. 즉, 코드 변경 없이도 능률적으로 작업이 가능합니다.

옵션

인스턴스에 여러가지 옵션도 부여할 수 있습니다..

위치,회전, 생성위치

EnemyPathFollowes enemy = Instantiate(

enemyPrefab,

spawnPoint.position,

spawnPoint.rotation,

enemiesParent

);

rigid body(예시)

GameObject instance = Instantiate(

target,

spawnPosition.position,

spawnPosition.rotation

);

instance.GetComponent<Rigidbody>().AddForce(0, 1000, 0);
