Image Fill

최종 수정일: 2월 20일

정의

Fill은 Unity UI Imgae 컴포넌트가 가진 게이지(gague) 표현 방식 입니다. fillAmout 값에 따라 이미지가 가로/세로/원형 등 지정한 방향으로 비율만큼 채워진 상태로 렌더링됨. 체력/마나/경험치 같은 "현재값이 최대값에 대해 어느 정도 인지를 시각적으로 전달할 때 주로 사용 됨.

핵심 규칙

Fill을 쓰려면 Image의 Type이 Filled여야 함.

fillAmount는 0~1 범위의 정규화 값만 의미가 있음.

현재/최대 형태의 수치는 정규화(현재 + 최대) 후 사용해야 함.

최대값이 0이거나 너무 작을 수있으므로 0나누기 방지가 필수임.

값이 범위를 벗어나도 UI가 깨지지 않도록 Clamp(0~1 제한) 처리가 안전함.

Fill 방향/형태는 Fill Method/Origin/Clockwise 설정에 의해 결정됨.

Fill은 표시 계층이므로, 실제 수치의 신뢰성보다 안정적 렌더링 규칙을 우선으로 함.

구성요소(용어 정리)

Image(Typed : filled) : 채움 렌더링을 활성화하는 Image 타입

FillAmount : 채움 비율(0= 비어있음 1= 가득참)

Fill Method : 채워지는 방식(가로/세로/방사형 등)

Origin: 시작 방향(왼쪽/오른쪽/위/아래 원형 시작점)

Clockwise: 방사형 채움에 시계/반시계 방향 선택

정규화(Normalization) : 현재값을 최대값으로 나눠 0~1로 변환하는 과정

Clamp01: 값을 0~1로 강제 제한하는 처리

0 나누기 방지(Epsilon 체크): 최대값이 0 또는 극소일 때 게산을 회피하는 안전 처리

주의사항

Type이 Filled가 아니면 fillAmount를 바꿔도 시각 변화가 없을 수 있음.

fillAmount에 0~1 밖의 값이 들어가면 예상치 못한 표시가 나올 수 있어 제한이 필요함.

최대값이 0인 상황(초기화 전, 설정 누락 등)에서 정규화하면 Nan/Infinity가 발생해 UI가 깨질 수 있음.

Fill Method/Origin 설정이 잘못되면 체력바가 반대로 줄어든다. 처럼 방향 문제가 생김..

마스크/레이아웃/스프라이트 설정(특히 슬라이스)과 조합에 따라 채움이 의도와 다른 게 보일 수 있으니, 시각 결과를 기준으로 설정을 고정하는 것이 안전함.

매 프레임 갱신은 단순하지만, 필요 이상으로 자주 갱신하면 UI 갱신 비용이 누적될 수 있어 변경 시점 갱신도 고려해야 함.
