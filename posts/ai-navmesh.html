AI NavMesh

최종 수정일: 2월 20일

정의

AI NavMesh는 씬의 걸을 수 있는 표면을 NavMesh로 베이크 해두고 NavMeshAgent가 그 위에서 경로탐색 + 조향 + 회피를 수행하도록 하는 유니티 네비게이션 시스템임. 결과적으로 AI/플레이어 캐릭터가 복잡한 지형에서도 장애물을 피해 목표 지점까지 자연스럽게 이동 할 수 있음.

핵심 규칙

NavMesh는 걷는 영역만 포함되도록 베이크해야 함.(벽,절벽,물 등은 제외로 분리)

Agent 크기는 캐릭터 콜라이더와 이동 느낌에 맞춰야 합니다. 값이 안맞으면 끼임, 벽 비기기등 단절이 자주 생김.

이동 명려은 한 방식으로 일관되게 구성해야 함.(Agent의 이동/회전 업데이트 옵션을 켰는지, 직접 회전/이동을 섞는지에 따라 결과가 달라짐)

장애물은 NavMeshObstacle 또는 NavMesh에서 제외된 콜라이더로 정책을 분명히 함.

레이어/AreaMask/AgentType은 갈 수 있는 곳/없는 곳을 결정하는 핵심 필터이므로, 클릭 지점 선택(레이캐스트)과 경로 계산 필터가 서로 충돌하지 않게 맞춰야함.

구성요소

NavMesh: 걷기 가능한 표면을 다각형 메시로 표현한 내비게이션 데이터.

Baking: 씬의 지오메트리를 분석해 NavMesh를 생성하는 과정

Agent Type: 서로 다른 크기/이동 제약을 가진 에이전트 프리셋(사람/큰 몬스터등)을 구분하는 설정

NavMeshAgent: 경로 탐색과 이동, 회피를 수행하는 컴포넌트

NaveMeshObstacle: 에이전트가 피해야 할 장애물(선택적으로 Caving으로 NavMesh를 파냄)

Carving: 장애물 주변의 Navmesh를 런타임에 깍아 우회 경로를 유도하는 방식

Area/ Area Mak: 영역 타입과 에이전트가 통과 가능한 영역을 지정하는 필터

Off-Mesh Link: 점프/사다리/문 통과처럼 NavMesh 폴리곤이 끊기 구간을 연결하는 링크

Avoidance(회피): 주변 에이전트/장애물과의 충돌을 줄이기 위한 속도/방향 조정 로직

유사함수

NavMeshAgent.SetDestination: 목표 지점을 주로 경로를 게산하고 이동을 시작함.

NavMeshAgent.Move: 외부에서 이동 벡터를 주입해 NavMesh 위에서 상대 이동 시킴.

NavMesh.CalculatePath: 실제 이동 없이 경로만 계산해 유혀성/길찾기 가능 여부를 판단함.

NavMeshAgent.Warp: 경로 계산을 무시하고 NavMesh 위의 특정 지점으로 즉시 이동시킴.

주의사항

Agent Radius/ Step Height/Max Slope가 지형과 안맞으면 NavMesh가 끊기거나 통로가 막힘.

NavMesh가 어떤 오브젝트를 베이크 솟스로 포함하는지 부터 먼저 확정해야함.

Agent 이동은 한 정책으로 통일해야함.

회전 업데이트 정책을 명확히 해야함.

Area/Area Mask와 클릭 레이어/판정 규칙이 서로 충돌하지 않게 맞춰야함.
