Unity Event & C# Event & Action

최종 수정일: 1월 26일

Unity Event

Unity에서 제공하는 이벤트 시스템으로 Inspector에서 시각적으로 이벤트를 연결하고 관리할 수 있게 해주는 기능입니다.

Unity Data Event Data Flow

유니티이벤트 정의 -> 인스펙터에서 연결 -> AddListenter 연결 ->Invoke 호출

특징

Unity Inspector에서 직접 연결 가능 합니다.

직렬화 지원 합니다. (Scene에 저장 가능)

런타임 중에도 동적으로 리스너 추가/제거 가능 합니다.

주로 사용 하는 곳

UI 버튼 클릭 이벤트

씬 전환 이벤트

애니메이션 이벤트 트리거

Inspector에서 설정이 필요한 게임 이벤트

C# Event

특정 상황이 발생했음 을 다른 클래스에게 알리는 메커니즘 입니다.

특징

캡슐화가 잘 됩니다.

성능이 가장 좋습니다.

코드 기반으로만 구독 가능 합니다.

속도가 유니티 이벤트보다 빠릅니다.

주로 사용 하는 곳

게임 상태 변경 통지 합니다.

캐릭터 상태 변경 알립니다.

시스템 간 통신 합니다.

데이터 모델 변경 알립니다.

C# Event Data Flow

이벤트 정의 -> 구독자 등록 -> 이벤트 발생 -> 구독자들의 메서드 실행

Action

델리게이트의 한 종류로 변환값 없는 메서드를 참조 할 수 있는 타입 입니다.

Action Data Flow

Action 실행 -> 람다식으로 연결 -> 직접 메서드 연결 -> Invoke로 호출

특징

가장 간단한 구현 입니다.

람다식 사용 가능 합니다.

일회성 이벤트에 적합 합니다.

구독자 관리가 다소 어려움이 있습니다.

주로 사용하는 곳

비동기 작업 완료 콜백

임시 이벤트 처리

간단한 함수 콜백

람다식을 활용한 동적 이벤트 처리

Action vs Event Action 차이

Action : 누구나 직접 호출, 할당, null등 설정가능 합니다. (캡슐화 X)

Event Action : 선언된 클래스 내부에서만 호출가능, 외부에서는 구독/해제만 가능 합니다. (캡슐화 O)
